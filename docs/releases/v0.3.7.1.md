## Changes

This small hotfix builds on v0.3.7 with a fieldset styling fix and expanded browser tests.

- Keep the editor fieldset borderless when the Dolibarr host theme overrides native fieldset borders, including in Firefox.
- Test Chromium, Firefox and WebKit on Linux, Windows and macOS in CI, including light and dark themes at mobile and desktop widths.
- Run mock browser tests in parallel with isolated state per test attempt and separate screenshot output paths.
- Detect unsupported virtual-camera streams and verify the fallback error on those browser builds.

## Updating

Install the matching module and service packages. This hotfix adds no database migrations. Updates from v0.3.6 or earlier still require the JSON-to-SQLite migration precautions described in the [v0.3.7 release notes](v0.3.7.md) and [update guide](../updating.md).

- `module_qrrouter-v0.3.7.1.zip`: installable Dolibarr module, including the built interface.
- `qrrouter-service-v0.3.7.1.zip`: matching portable service; requires the .NET 10 ASP.NET Core Runtime.
