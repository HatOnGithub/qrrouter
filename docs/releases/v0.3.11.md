## Changes

- Search bins on the Bins and locations page. Leaving the bin filter empty shows the whole warehouse inventory, including items without a bin assignment.
- Create inventory reports for a whole warehouse, a location level or a single bin.
- Configure location levels using rows with an Add button. Choose text, numbers, letters or a custom option list for each level; existing assignments and option identities are protected.
- Select English, Dutch or French output for printable labels, location reports and picking sheets independently of the interface language.
- Create picking sheets for manufacturing order components as well as customer orders. Picking sheets remain planning previews and do not reserve or decrement stock.
- Add vertical padding to full-width card and scanner buttons.

## Updating

Install both matching packages, retaining the existing service configuration and data directory. Back up the Dolibarr database and QR Router service data together before updating. Existing QR entries, location definitions and assignments are retained. See the [update guide](../updating.md).

- `module_qrrouter-v0.3.11.zip`: Dolibarr module including the built interface.
- `qrrouter-service-v0.3.11.zip`: matching portable service; requires the .NET 10 ASP.NET Core Runtime.
- `SHA256SUMS`: checksums for both packages.
